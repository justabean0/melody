# Project Operating Guidelines: GSD, UI/UX Pro Max, SkillX

This project operates under the combined framework of **GSD (Get Shit Done)**, **UI/UX Pro Max**, and **SkillX**:

- **GSD (Spec-Driven Execution)**: Work proceeds methodically from specification to implementation, verified by tests and analyzer checks before moving forward.
- **UI/UX Pro Max (Design Intelligence)**: Every UI screen, component, and animation is designed to production-grade mobile standards with proper safe-area padding, cohesive Material 3 palettes, 48dp touch targets, and responsive layouts.
- **SkillX (Hierarchical Skill Architecture & Fast Feedback)**: Problems are decomposed into strategic, functional, and atomic layers, with immediate adaptation based on compiler and runtime feedback.
